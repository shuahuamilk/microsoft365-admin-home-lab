# Lab 1.3 – Block Sign-In

## Objective

Learn how to temporarily prevent a user from signing in to Microsoft 365 without deleting their account.

## Steps

1. Sign in to Microsoft 365 Admin Center.
2. Go to Users > Active users.
3. Select the test user.
4. Open Account.
5. Enable Block sign in and save.
6. Verify the account is blocked.

## Discussion Questions

1. Why block instead of delete?
* Preserves data while preventing access.
2. Does it delete data?
* No.
3. Can access be restored?
* Yes, unblock sign-in.
4. When should it be used?
* Leave, suspension, security incidents.
